# GitHub Pages — предпросмотр BRAVIS

После выбора владельцем **Settings → Pages → Build and deployment → Source: GitHub Actions** сайт публикуется из сборки в `.github/workflows/pages-preview.yml`.

Адрес предпросмотра: https://denisgromahnm-lang.github.io/bravis-site/

**Важное:** это публичный тестовый адрес, не официальный сайт BRAVIS. Пока активен `noindex`, владелец не разрешил production, а домен `bravisrest.ru` ожидает идентификации в REG.RU. Не меняйте DNS и не используйте Timeweb для этой сборки.

## Бронирование

Все кнопки «Забронировать стол» ведут к форме ресторана СмартРезерв, ID `5b1e469e-871a-4eb8-bd2a-787ec2d011c3`. Числовой ID `503266819` принадлежит iiko и не используется как URL формы.

## Как проверять
1. Откройте адрес выше, дождитесь публикации в Actions (workflow `Publish noindex BRAVIS preview to GitHub Pages`).
2. На главной странице нажмите «Забронировать стол» и убедитесь, что открывается нужный ресторан в Яндексе.
3. Откройте меню и проверьте пять разделов и полноэкранный просмотр.
4. Проверьте с телефона главную страницу, меню и кнопку бронирования.
5. Предпросмотр не гарантирует, что СмартРезерв ↔ iiko синхронизирует бронь; интеграция проверяется отдельно.

GitHub Actions повторно строит предпросмотр после каждого изменения исходников в каталоге `site/`.
