# Гостевой хаб /go/

Статическая страница для гостя, который уже сидит за столом. Основная карта Loona 4992 открывается первой; меню ланча, вечер, мероприятия, следующий визит и оба способа обратной связи доступны всегда. Онлайн-заказ не реализован и не имитируется.

Существующие site.js и механизм согласия на аналитику не меняются. На /go/ произвольные query/hash удаляются до запуска аналитического helper; если очистка браузером запрещена, аналитика на этой странице пропускается без изменения сохранённого выбора. Хаб использует текущую цель reserve_click только для существующей формы бронирования; других новых целей, счётчиков, форм и backend нет.

## Режим ланча

Пн–пт, 11:00 включительно — 16:00 исключительно, Europe/Moscow. В это окно меню ланча второе; вне окна выше поднимаются обычное меню и мероприятия. Все ссылки остаются в DOM. При отключённомJS или ошибке времени работает статическая страница без обещания «сейчас ланч».

В content/guest-hub.json исключение 2026-11-04 пока unconfirmed. До подтверждения администратора нет утверждения о работе или закрытии ланча. Поддерживаемые состояния:
- unconfirmed — уточнить у сотрудника;
- regular_lunch_confirmed — обычные часы;
- no_lunch_confirmed — подтверждённое отсутствие ланча в этот день;
- special_hours_confirmed — подтверждённые start/end в формате HH:MM.

Менять исключение только по подтверждённому операционному факту. Оно относится к одной дате, не ко всем средам. При отсутствии JS остаётся общая оговорка о праздничном режиме.

## Карта гостя

Точная основная ссылка 4992 берётся из существующего site.config.json. Дополнительная 5047 не продвигается. Новых обещаний баллов, процентов, штампов и событий нет. Наличие четырёх сценариев в кабинете, включая приветственный, ещё не доказывает статус и корректность начислений. При проверенном отключении регистрации loonaEnabled=false оставляет пояснение и остальные рабочие ссылки.

## Проверка

Из site/:
- python3 src/build.py
- python3 scripts/render_menu_gallery.py
- python3 verify.py
- python3 scripts/quality_gate.py --production-guard
- штатным Python с Playwright: python3 scripts/guest_hub_acceptance.py
- python3 scripts/browser_smoke.py
- python3 scripts/prepare_github_pages.py && python3 scripts/test_pages_preview.py

Для production использовать существующий scripts/build_timeweb_release.py --output NEW_DIRECTORY. Он не выполняет деплой. После выпуска проверить/go/ в основном домене и только затем печатать QR. Маршрут не требует новой подписки, нового сайта или завершённой кассовой логики5047. Отправки броней, регистраций, SMS и тестовых покупок для этой подготовки не нужны.

## Промо над кнопками

Один компактный блок настраивается в content/guest-hub.json: promo.lunch и promo.evening. Во время подтверждённого рабочего окна ланча показаны 690 ₽, пн–пт 11–16 и оригинальное меню business.jpg со ссылкой /lunch/. Вне окна, без JS, при ошибке часов и 4 ноября с неподтверждённым режимом — «Соберитесь своей компанией», реальное фото зала и ссылка /banquets/. Все семь прежних ссылок остаются доступны. Блок не объявляет новую акцию, событие, вместимость или сумму бонусов.


## Мобильная навигация и единая цена

На мобильных экранах специальная шапка остаётся при прокрутке и содержит кнопку «Меню» высотой не менее44px. После400px появляется существующее средство «Наверх», с SVG-стрелкой и учётом cookie/safe-area. Главная кнопка карты использует существующее согласие и событиеloona_signup_click; переход не означает завершение регистрации. Цена промо подставляется из того же lunch_price, что и меню, через один буквальный плейсхолдер{price}, без отдельной числовой цены в настройках.
