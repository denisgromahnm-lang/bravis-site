### Цели Яндекс Метрики
После создания счётчика открыть «Цели» → «Добавить цель» → тип «Целевое событие».
Настроить с идентификаторами **точно как в коде**:

| Название в Метрике | Идентификатор |
|---|---|
| Переход к бронированию стола | `reserve_click` |
| Открытие меню с главной | `menu_from_hero` |
| Просмотр сезонного меню | `menu_open_seasonal` |
| Просмотр основного меню | `menu_open_main_front` |
| Просмотр барной карты | `menu_open_main_back` |
| Просмотр бизнес-ланча | `menu_open_business` |
| Просмотр детского меню | `menu_open_children` |
| Звонок с шапки сайта | `header_phone_click` |
| Обращение по банкету | `banquet_phone_click` |

Важно: «Переход к бронированию» не означает «Бронь подтверждена»; результат брони фиксировать только при наличии документированного callback / выгрузки из СмартРезерва. После создания цели могут не получать события, пока счётчик не установлен на работающий сайт и пользователь не разрешил аналитику.

## Яндекс Метрика
Счётчик уже создан для `https://bravisrest.ru` в аккаунте владельца. Числовой ID `113768615` уже внесён в `site/site.config.json` → `yandexMetrikaId`. Сайт загружает код счётчика только после согласия посетителя на аналитику (кнопки «Без аналитики» / «Разрешить»).

События, уже предусмотренные в HTML/JS: 
- `reserve_phone_click`, `reserve_mobile_click` — нажали на телефон или кнопку резерва;
- `reserve_click` — открыли внешнюю форму СмартРезерва;
- `header_phone_click`, `footer_phone_click`, `contacts_phone_click` — клики по номеру;
- `menu_from_hero`, `menu_from_feature` — открытие меню из главной страницы;
- `menu_open_seasonal`, `menu_open_main_front`, `menu_open_main_back`, `menu_open_business`, `menu_open_children` — просмотр каждого утверждённого раздела меню;
- `banquet_phone_click` — обращение по банкету.

Состав целей нужно сверить в кабинете счётчика после запуска. Клик «Забронировать» **не равен успешно подтверждённой брони**. Событие подтверждения добавлять только при документированной передаче результата Яндексом (callback/postback/API).

## Индексация
- Яндекс Вебмастер: подтвердить владение сайтом (метатег `verificationYandex`) и передать sitemap.
- Google Search Console: подтвердить владение (`verificationGoogle`) и передать sitemap.
- Яндекс Бизнес, 2ГИС: подтвердить владельца карточек, установить официальный URL, сверить название, адрес, телефон, часы работы.
- Яндекс Директ: отдельная настройка кампании и целей; бюджет не устанавливаем автоматически.
- Google Analytics 4 (необязательно): `ga4Id` только при согласовании.
- `robots.txt` и `sitemap.xml` становятся открытыми **только когда** `public=true` и указан HTTPS-домен.

## Дополнительные проверки
На телефоне проверить клики по номеру, меню, фотографии, бронированию и банкетам. Проверить отображение чекбокса согласия в системе Яндекса, а не имитировать собственный сбор телефона и имени. Проверить canonical, микроразметку `Restaurant`, OG-картинку, статусы 404 и отсутствие смешанного HTTP-контента.

До разрешения владельца не подключать платную аналитику, платные кампании или сторонние пиксели.
