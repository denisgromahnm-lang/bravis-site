# BRAVIS — статический сайт ресторана

Сайт подготовлен без npm: HTML/CSS/JS + сборка Python 3 из исходных данных.
Фотографии импортируются из публичной папки Яндекс Диска, без передачи с ноутбука.

## Подготовка

```bash
python3 src/import_yandex.py --list
python3 src/import_yandex.py --download --max 12
python3 src/build.py
```

Не следует выдавать отсутствие фото, меню или ID бронирования за готовую функцию.
В `site.config.json` до публикации `public=false`; поисковая индексация отключена.

## Безопасное обновление существующего предпросмотра

```bash
bash install-preview.sh /home/a4dev/bravis-site
```

Скрипт создаёт резервную копию `dist`, проверяет новые ассеты и обновляет файлы статического предпросмотра **внутри существующей директории `dist`**. Это важно, если веб-сервер уже запущен из этой директории. Исходники Astro и работающие службы не трогает.

## Состояние основного сайта

Сайт опубликован на https://bravisrest.ru/ через существующий Timeweb App 278139. `site.config.json` намеренно хранит безопасный noindex-предпросмотр; основной выпуск накладывает `production.config.json`. Актуальные выполненные и открытые пункты — в `docs/LAUNCH.md`, аналитика — в `docs/ANALYTICS_SEO.md`. Полное завершение проекта пока не подтверждено.

Проверка основного выпуска: `python3 scripts/check_launch_readiness.py --production --strict`. Она учитывает production overlay и обнаруживает рабочий проект политики, даже если старый флаг согласования включён.

## Бизнес-ланч

Страница `/lunch/` показывает блюда по будням из `content/lunch.json`; они сверены с оригинальным `public/menu-media/business.jpg`. Цена комплекса берётся из раздела `lunch` в `content/menu.json`. Без JavaScript видны все дни, с JavaScript работают доступные с клавиатуры вкладки. Время подачи и актуальность меню уточняются у ресторана; неподтверждённые часы и акции не добавляются.
