# BRAVIS — официальный сайт ресторана (предпросмотр)

Рабочий статический проект без зависимости от npm, создан для ресторана BRAVIS на улице Расковой, 20, Москва.

## Развернуть безопасный предпросмотр на уже настроенном Timeweb

Существующая директория: `/home/a4dev/bravis-site/dist`. Прямая загрузка с ноутбука не нужна.

В веб-консоли российского VPS:

```bash
curl -fsSLo /tmp/bravis-deploy.sh https://raw.githubusercontent.com/denisgromahnm-lang/bravis-site/a227fe66184cfac942017b17b84e29aa7a69c248/scripts/deploy-preview.sh && bash /tmp/bravis-deploy.sh
```

Скрипт:
1. При запуске от root переключается на пользователя `a4dev` (при наличии `runuser`).
2. Загружает **закреплённую по коммиту** версию архива `81d627d` и проверяет SHA-256.
3. Загружает до 12 фотографий из публичного Яндекс Диска в каталог релиза.
4. Собирает и проверяет HTML/CSS/JS и локальные пути картинок.
5. Делает резервную копию старого `dist`, обновляет содержимое **внутри существующей директории**. Туннель предпросмотра, DNS, сервисы A4 REST AI и настройки сервера не меняет.

После выполнения откройте существующую защищённую ссылку Cloudflare и нажмите **Ctrl+F5**.

## Статус

- Пять страниц: главная, меню, банкеты, контакты, политика данных.
- Сборка и локальная проверка статических файлов пройдены.
- До получения ID СмартРезерва бронирование по телефону (не выдается за онлайн-бронь).
- Меню и цены пока отсутствуют, нельзя публиковать фиктивные позиции.
- До подтверждения реквизитов и юридического текста политика данных — черновик.
- Индексация тестовой версии отключена (`noindex`).
- Развертывание на VPS и работа Cloudflare должны быть подтверждены отдельно.

## Перед запуском bravisrest.ru

Подтвердить факт регистрации домена, согласовать актуальные часы работы, меню с ценами, SmartReserve ID, реквизиты оператора данных, подключить Яндекс Метрику и Вебмастер, проверить HTTPS и рабочую бронь. Только после этого разрешать индексацию.

Архив исходников (base64+gzip): `release/bravis-site.tar.gz.b64`. Установка: `scripts/deploy-preview.sh`.


## Дополнительная медиапапка ресторана (24 октября 2026)

Вторая публичная папка: https://disk.yandex.ru/d/mM7bPzFGD0o2WA.

Загрузчик: [scripts/import_additional_media.py](scripts/import_additional_media.py).
Установщик: [scripts/install_extra_media.sh](scripts/install_extra_media.sh).

Запускать **только на российском сервере** `9394005-on250182`:

```bash
curl -fsSLo /tmp/bravis-extra-install.sh https://raw.githubusercontent.com/denisgromahnm-lang/bravis-site/c00136351d4dcc63090ce3988836f5156aa8572e/scripts/install_extra_media.sh && bash /tmp/bravis-extra-install.sh
```

Скрипт проверяет hostname, локальный каталог предпросмотра, закреплённый SHA256 релиза, переносит уже импортированные фото в рабочую копию, скачивает не более 14 новых фотографий и 24 изображений/PDF меню (общий лимит 140 MiB), затем собирает и устанавливает **только предпросмотр**. Перед заменой `dist` создаётся резервная копия. Домен, DNS, A4 REST AI и работающие службы не изменяются.

Имена и расположение файлов в новой папке ещё не были просмотрены автором: если скрипт не распознает меню, вернёт отчёт, но не будет сочинять цены. До публикации обязательно визуально проверить достоверность меню и дату цен. Текстовые названия блюд, цены и составы в структурированное меню не переносятся автоматически.
