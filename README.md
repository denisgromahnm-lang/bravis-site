# BRAVIS · официальный сайт ресторана

**Москва, улица Расковой, 20 · армянская и европейская кухня · встречи и вино**

Этот репозиторий содержит исходники нового сайта ресторана BRAVIS. Разработка происходит **здесь, в GitHub**, отдельно от серверов Timeweb и проекта A4 REST AI.

> **Статус: предварительная версия.** Индексация отключена. Не используйте тестовый адрес как официальный сайт, пока не подтверждены домен, юридические реквизиты, цены и Яндекс СмартРезерв.

## Сайт

Главная `/`, меню `/menu/`, банкеты `/banquets/`, контакты `/contacts/`, политика данных `/privacy/`.

Вёрстка оптимизирована для мобильного просмотра. Меню открывается по пяти категориям, отдельные PDF заменяются проверенными изображениями без дубликатов страниц. Успешное бронирование не имитируется: до выдачи ID СмартРезерва работает звонок в ресторан.

Сайт работает на статических HTML/CSS/JS; **не требует npm, коммерческих конструкторов или платного ИИ**. Для локальной сборки достаточно Python 3:

```bash
cd site
python3 src/build.py
python3 scripts/render_menu_gallery.py
python3 verify.py
```

Импорт оригинальных изображений использует Python Pillow и Poppler на GitHub Actions; они не нужны для просмотра уже готового сайта.

## Важно о материалах

- Интерьер, фасад: только материалы из [первой папки Яндекс Диска](https://disk.yandex.ru/d/9up8OtV4hsMOZg).
- Меню: только утверждённые версии из [второй папки](https://disk.yandex.ru/d/mM7bPzFGD0o2WA).
- Из двух одинаковых страниц основного меню и двадцати одинаковых страниц бизнес-ланча оставляем по одной.
- Детское меню: **только PDF**, не исходный файл Adobe Illustrator.
- Новые фотографии **не назначаются карточкам блюд**. Для еды допустимы только старые подтверждённые снимки.
- Выдуманные блюда, цены и реквизиты запрещены.

## GitHub Actions

| Проверка | Назначение |
|---|---|
| **Bootstrap BRAVIS readable source** | Один раз развернул архив в обычные файлы |
| **Validate BRAVIS website** | Проверка сборки, ссылок, мобильных ресурсов, SEO и noindex |
| **Prepare BRAVIS approved media and website** | Загружает фотографии и пять оригинальных меню с Яндекс Диска, удаляет дубликаты, сохраняет готовые ресурсы |
| **Publish private-stage BRAVIS preview to GitHub Pages** | Отдельный публичный тестовый предпросмотр **без индексации** после включения Pages в настройках репозитория |

GitHub Pages-предпросмотр требует включения **Settings → Pages → Source: GitHub Actions** владельцем. Без этого доступна проверенная сборка в Actions → Artifacts; на Timeweb ничего не передаётся.

## Переход в production

После регистрации `bravisrest.ru`, получения ID Яндекс СмартРезерва, счётчика Метрики, подтверждения меню, расписания и реквизитов оператор данных заполняет конфигурацию. Только после проверки рабочего бронирования, SSL и SEO владелец включает индексацию.

**Не запускать исторические команды из каталога [scripts/](scripts/) на Timeweb.** Они относятся к предыдущим экспериментальным версиям. Сейчас вся разработка находится в `site/`.
